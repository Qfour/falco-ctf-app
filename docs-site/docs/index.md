# はじめに

ようこそ。これは **Falco CTF** イベントの課題資料サイトです。

## 表示名について

スコアボードに出る名前は **デフォルトで識別子(`user1` など)** です。
ワークスペースのターミナルで、好きな表示名にいつでも何回でも変更できます:

```bash
source /opt/ctf/setname.sh && setname 'あなたの名前'
```

識別子と表示名は別物です。提出や認証は識別子で動き、スコアボードの
**表示だけ**が指定した名前に置き換わります(1〜32 文字、`< > & " '`
と制御文字は使えません)。

## Falco とは

[Falco](https://falco.org/) は、コンテナ・ホスト上の **syscall をリアルタイム監視**する
OSS のランタイムセキュリティツールです。攻撃者が侵入後に行いがちな挙動
(機密ファイル読み取り・リバースシェル・クレデンシャル探索 …)を kernel レベルで
観測し、ルールに合致したら即座にアラートを出します。

この CTF では、攻撃技術を実際に手で実行しながら **Falco がどう検知するか** を学びます。
課題には 2 種類あり、**Falco を発火させること自体が目的の課題**と、
**発火させずに目的を達成する(検知を回避する)ことが目的の課題**があります。
攻撃側の視点と、それを見張る側(検知)の視点を、同じ手順を通して両方体験できる構成です。

参加者ひとりにひとつのコンテナ環境(ワークスペース)が割り当てられ、
その中で一連の課題を順番に進めていきます。全体の流れ(キルチェーン)や
現在地の確認は **STORY タブ** から行えます。まずそちらでミッションの並びを
ひととおり見てから、最初のミッションに着手するのがおすすめです。

!!! tip "ワークスペースとの併用"
    手を動かす環境は各自のワークスペース(Web ターミナル)です。
    このサイトは**読み物**として、ワークスペースと並べて参照してください。

## 推奨スキルレベルと前提知識

課題はすべて **Linux のターミナル(シェル)上で手を動かして** 解きます。
事前に以下があると、課題そのものに集中でき、スムーズに進められます。

- **Linux 基本コマンド操作(必須)** — `cd` / `ls` / `cat` / `grep` / `find` /
  パイプ(`|`)・リダイレクト(`>` `>>`)・環境変数など、ファイルを読み書き探索する
  一連の操作に抵抗がないこと。
- **ターミナル / テキストエディタ操作(必須)** — Web ターミナル上での入力・コピー&
  ペースト、`vi` または `nano` での簡単なファイル編集ができること。
- **コンテナの基礎理解(あると有利)** — コンテナ / プロセス / syscall がおおよそ
  何を指すかのイメージ。Falco が「何を監視しているか」の理解が深まります。
- **セキュリティ / 攻撃の基礎(あると有利)** — 偵察・権限昇格・永続化・持ち出し
  といった攻撃の流れ(キルチェーン)を知っていると、[ストーリー](story.md)の
  各ミッションの位置づけが掴みやすくなります。

!!! note "難易度の目安"
    Linux コマンドを日常的に触っている人であれば、専門的なセキュリティ知識が
    なくても解き進められる構成です(**初級〜中級**)。前提知識は課題本文と、
    `/journey` の各ミッションページで段階的に開ける **ヒント**(気付き → 概要 →
    解答)で補えるので、Falco や攻撃手法が初めてでも心配いりません。まず
    [ストーリー](story.md) を読んで全体像を掴んでから、ミッション 01 に進むのが
    おすすめです。
