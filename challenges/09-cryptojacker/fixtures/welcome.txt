# シナリオ

C2 接続は確保した (Mission 08)。だがあなたの真のお目当ては別。
NimbusCorp の本番クラスタは EKS の m5.xlarge × 数百ノード。
**マイナーを 1 台ずつ仕掛ければ立派な現金製造機**になる。
さっそく xmrig を起動しよう。

# ゴール

このコンテナで Falco の crypto miner 検知ルールを発火させる。

# 背景

Falco の miner 検知は主に 2 系統:

1. **proc.name ベース** — `xmrig` / `minerd` / `cpuminer` 等、既知の
   miner binary 名を見る
2. **protocol ベース** — outbound 通信に `stratum+tcp://` 文字列が
   含まれる場合 (CTF 環境では NetworkPolicy で block されるので
   こちらは発火させにくい)

ここでは proc.name ベースを使う。**実行ファイルの basename を "xmrig"**
にすれば、内容は何でも (sleep でも) 検知される。

# 試すこと

  sh /opt/ctf/fixtures/start-miner.sh

これは内部で:
  1. `/bin/sleep` を `/tmp/xmrig` にコピー
  2. その basename = "xmrig" として exec
  3. Falco: proc.name = "xmrig" → 発火

# クリア条件

crypto miner 検知ルールが発火する。

# 環境にあるもの

  /opt/ctf/fixtures/welcome.txt    ← このファイル
  /opt/ctf/fixtures/start-miner.sh ← fake xmrig 起動シナリオ

────────────────────────────────────────────────────────────────────
HINT 1 (易): 一発実行
────────────────────────────────────────────────────────────────────

  sh /opt/ctf/fixtures/start-miner.sh

────────────────────────────────────────────────────────────────────
HINT 2 (中): 自分で組む
────────────────────────────────────────────────────────────────────

  cp /bin/sleep /tmp/xmrig
  /tmp/xmrig 30 &

basename "xmrig" → proc.name "xmrig" → miner 検知ルールが発火。
中身は何でも (sleep / true / 単なる無限ループでも) OK。

────────────────────────────────────────────────────────────────────
HINT 3 (Mission 10 への伏線)
────────────────────────────────────────────────────────────────────

このルールも **basename ベース**。Mission 06 で学んだのと同じ手口で
回避できる: 別名にすれば検知されない。
