# シナリオ

ここまでで Mission 03 / 05 を解いたあなたは「Falco は文字列で見て
いる、回避できる」と確信している。だが CTF Company の Web サーバには
別の脆弱性もある — Java の `Runtime.exec()` 経由で OS shell が起こ
せる、典型的 Web RCE。**実際に Web プロセス偽装で shell を起こすと
何が起こるか** を体験せよ。

# ゴール

このコンテナで Falco ルール「Run shell untrusted」を発火させる。
発火 = solve。

# 背景

Falco が見るのは **shell プロセスの親の comm (proc.pname)**:
- 親が `bash` / `sh` / `zsh` 等 → 普通のオペレータ操作。発火しない
- 親が `httpd` / `nginx` / `apache2` / `postgres` 等 → 異常。発火

Linux カーネルは `/proc/<pid>/comm` を **実行ファイルの basename**
から決めるので、自分でファイル名を選んで実行ファイルを置けば
proc.pname をコントロールできる。

# 試すこと

fixtures に用意されたラッパーをそのまま実行:

  sh /opt/ctf/missions/06-web-rce-shell/fixtures/fake-httpd.sh

これは内部で:
  1. `/tmp/httpd` という shell スクリプトを書き出し (comm = "httpd")
  2. それを exec
  3. `/tmp/httpd` の中で `/bin/sh -c "..."` が走る
  4. Falco: 親 comm = "httpd" → shell 起動 → 発火

# クリア条件

`Run shell untrusted` が発火する。

# 環境にあるもの

  /opt/ctf/missions/06-web-rce-shell/fixtures/welcome.txt    ← このファイル
  /opt/ctf/missions/06-web-rce-shell/fixtures/fake-httpd.sh  ← Web RCE シナリオ

────────────────────────────────────────────────────────────────────
HINT 1 (気付き): Falco は shell の「親」を見ている
────────────────────────────────────────────────────────────────────

shell 起動が怪しいかどうかは **親プロセスが何か** で決まる。
bash から sh を呼ぶのは正常。では `httpd` や `nginx` のような
Web サーバが shell を起こしたら? Falco はそれを異常と見なす。

────────────────────────────────────────────────────────────────────
HINT 2 (概要): proc.pname は実行ファイル名で決まる
────────────────────────────────────────────────────────────────────

カーネルは proc.pname を **実行ファイルの basename** から決める。
`httpd` という名前の実行ファイルを置き、その中から shell を起こせば
「Web サーバが shell を起こした」ように見えて発火する。

────────────────────────────────────────────────────────────────────
HINT 3 (解答): httpd 偽装で shell を起こす
────────────────────────────────────────────────────────────────────

用意済みラッパーを実行:

  sh /opt/ctf/missions/06-web-rce-shell/fixtures/fake-httpd.sh

自分で組むなら:

  cat > /tmp/httpd <<'EOF'
  #!/bin/sh
  /bin/sh -c "ls > /dev/null"
  EOF
  chmod +x /tmp/httpd && /tmp/httpd

(逆に `cp /tmp/httpd /tmp/myscript && /tmp/myscript` のように **別名**
で動かすと親 comm が変わり発火しない — Mission 10 で使う回避の種)
