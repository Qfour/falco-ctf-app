# 目的

**EVADE 課題** — `/opt/nimbus/vault/creds.recover` に**この Mission 用の flag
だけ**が書かれている。Falco ルール「Read sensitive file untrusted」を**発火
させずに** flag を取り出し、scoreboard に提出する。

このルールが一度でも発火すると検知されたと判定され、**やり直すまで提出
できない**（時間が経っても自動的には解除されない）。

# 攻略ヒント

手順とコマンドは、ポータルの **Story タブ**（Journey UI）にある段階ヒント
「気付き → 概要 → 解答」から開く（開示するとスコアが段階的に減点される）。
この端末はコマンドを実行する場所で、攻略手順そのものはここには置かない。

# 提出方法

  source /opt/ctf/submit.sh
  submit 03-stealth-read 'FALCO{...}'

レスポンス:
  {"correct":true,"evaded":true,"solved":true,"user":"alice"}    ← 成功
  {"correct":true,"evaded":false,"reason":"forbidden rule..."}    ← 発火していた
  {"correct":false,"reason":"flag mismatch"}                       ← flag 違い

`evaded:false` が出たら、この attempt は検知済み。**待っても解除されない**。
Story タブの「このミッションをやり直す」ボタンでやり直してから、もう一度
`submit` すること。

# 環境にあるもの

  /opt/ctf/missions/03-stealth-read/fixtures/welcome.txt   ← このファイル
  /opt/ctf/submit.sh     ← `source` して使う
