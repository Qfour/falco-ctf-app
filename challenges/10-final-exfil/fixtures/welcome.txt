# シナリオ

ついに目的のターゲットに辿り着いた — NimbusCorp の本番 RDS
master password が `/etc/shadow` の末尾、`# NIMBUS_FINAL:` で始まる
行に書かれている (なぜそこに置かれているかは聞くな、ストーリーだ)。

これを取り出して持ち帰れば operation 完遂。**だが** ここまでの
Mission で学んだ **すべての検知ルール** を、**30 秒の window 内で
1 つも発火させてはいけない**。雑なコマンドを 1 つ打てば 30 秒待ち
直し。

# ゴール

`/etc/shadow` の末尾、`# NIMBUS_FINAL: FALCO{...}` 行から flag を
取り出して提出。**直前 30 秒間に 6 つの禁止ルールのいずれも発火
させていないこと**。

# 戦略

ここまで学んだテクニックを **組み合わせる**:

  Mission 03 のテクニック → /proc/self/root 経由で /etc/shadow を読む
                            (Read sensitive file untrusted を回避)
  Mission 05 のテクニック → 入力リダイレクトで cmdline 隠し (今回は不要)
  Mission 06 のテクニック → shell 起こすなら別名で
  Mission 08 のテクニック → ネットワークツール使うなら別名で

# 提出方法

  source /opt/ctf/fixtures/submit.sh
  submit 'FALCO{...}'

レスポンス:
  {"correct":true,"evaded":true,"solved":true,...}  ← Operation 完遂
  {"correct":true,"evaded":false,"reason":"forbidden rule(s) [...] fired in the last 30s..."}

`evaded:false` だったら **30 秒** 静かに待ち、もう一度 `submit`。
(他の Mission の探索で発火した記録が残っている可能性大)
