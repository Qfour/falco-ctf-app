# 目的

**EVADE 課題 (BOSS)** — 2 段すべてを満たすと solve (提出操作は不要 — 自動判定):

  (1) master key を **発火させずに読む**
      /opt/nimbus/vault/master.key の中身
  (2) 読んだ flag を **drop server (collector) へ HTTP で持ち出す**

このミッションに取り組んでいる間、上の 7 つの禁止ルールを 1 つも発火させて
いないこと。**一度でも発火すると、待っても解除されない** — Story タブの
「このミッションをやり直す」ボタンでやり直す必要がある。**やり直すと exfil の
記録も消えるので、(2) をもう一度行う必要がある。**

# 持ち出し先

reverse shell (C2) や自前バイナリの drop+実行は禁止ルールに触れる。箱に元から
ある道具だけで、collector (HTTP 受信のみ) へ静かに送ること。

  送信先:  POST /api/challenges/10-final-exfil/exfil  (collector)
  payload: {"user","flag"} の JSON

collector の URL と自分のユーザ名は、この端末の環境変数に入っている
(`env | grep CTF` で確認できる)。

# 攻略ヒント

手順とコマンドは、ポータルの **Story タブ**（Journey UI）にある段階ヒント
「気付き → 概要 → 解答」から開く（開示するとスコアが段階的に減点される）。
この端末はコマンドを実行する場所で、攻略手順そのものはここには置かない。

# 判定

提出操作は不要。exfil が collector に届いた時点で、7 つの禁止ルールを
1 つも発火していなければ、数秒以内に自動で solve と判定される (Story タブで
確認できる)。
