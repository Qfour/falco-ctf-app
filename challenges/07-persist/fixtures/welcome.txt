# 目的

**TRIGGER 課題** — Falco ルール「Drop and execute new binary in container」を
発火させると自動で CLEARED になる。提出操作は不要。
runtime に書いた binary は overlayfs の upper layer に積まれる。Falco は exec 時に
「base image に無い場所からの実行」を検知する。drop (書く) と execute (実行する)
の両方が条件。

この端末はコマンドを実行する場所で、攻略手順そのものはここには置かない。
