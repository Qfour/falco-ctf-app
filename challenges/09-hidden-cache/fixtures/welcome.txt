# 目的

**TRIGGER 課題** — Falco ルール「Create Hardlink Over Sensitive Files」を
発火させると自動で CLEARED になる (提出操作は不要)。
hardlink は inode への直接参照で、元ファイルを unlink されても中身は残る。
Falco は sensitive file への hardlink 作成も見ている。

# 攻略ヒント

手順とコマンドは、ポータルの **Story タブ**（Journey UI）にある段階ヒント
「気付き → 概要 → 解答」から開く（開示するとスコアが段階的に減点される）。
この端末はコマンドを実行する場所で、攻略手順そのものはここには置かない。

# クリア条件

`Create Hardlink Over Sensitive Files` がユーザ Namespace で発火する
→ 自動で CLEARED。
