# これは 0問目 — 遊び方の練習

ようこそ。この 00 は **採点に影響しない練習問題**。本番の 01→10 に入る前に、
「提出・ヒント・進行」の一連の流れをここで体験してほしい。

# 表示名について

scoreboard に出る名前は **default で識別子 (`user1` 等)**。好きな表示名に
変更できる (いつでも何回でも):

  source /opt/ctf/setname.sh && setname 'あなたの名前'

識別子と表示名は別物 — submit や認証は identity で動き、表示だけが display
name に置き換わる。1〜32 文字、`< > & " '` と制御文字は不可。

# 課題は 2 種類ある

- **TRIGGER** … あなたの操作で目標 Falco ルールを **発火** させると自動で
  CLEARED。提出フォームは不要。この 00 は trigger。
- **EVADE**  … 目標ルールを **発火させずに** flag を取り、フォームから提出。
  直前の数秒に禁止ルールが鳴っていると弾かれる。本番の 03/05/10 で体験する。

# ゴール (この 00)

このコンテナで Falco ルール「Execution from /dev/shm」を発火させる。
発火 = solve (提出操作は不要)。

# 背景

`/dev/shm` は共有メモリ上の書込可能領域。攻撃者はここに malware を置いて
実行する (ディスクに痕跡を残しにくい隠し場所)。Falco は「*何を* 実行したか」
だけでなく「*どこから* 実行したか」も見ている。

# 試すこと (安全な練習)

  echo 'echo hello from the tutorial' > /dev/shm/hello.sh
  sh /dev/shm/hello.sh

/dev/shm 上のスクリプトを shell で実行した瞬間にルールが発火する。実害はない。

# クリア条件

`Execution from /dev/shm` が発火する → 自動で CLEARED。scoreboard を見て
自分の行が進むのを確認しよう。
