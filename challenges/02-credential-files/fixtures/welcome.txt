# 目的

**TRIGGER 課題** — Falco ルール「Read sensitive file untrusted」を
発火させると自動で CLEARED になる (提出操作は不要)。
root しか読まない機密ファイル (例: /etc/shadow) は、コンテナの中で読んでも
検知される、という体験が狙い。

# 攻略ヒント

手順とコマンドは、ポータルの **Story タブ**（Journey UI）にある段階ヒント
「気付き → 概要 → 解答」から開く（開示するとスコアが段階的に減点される）。
この端末はコマンドを実行する場所で、攻略手順そのものはここには置かない。

# クリア条件

`Read sensitive file untrusted` がユーザ Namespace で発火する
→ 自動で CLEARED。
